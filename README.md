# ByteBloom E-commerce Analysis

## Project Overview
This project analyzes e-commerce customer transactions to understand sales performance, customer behavior, refunds, and customer loyalty.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Key Analysis
- Data cleaning and preprocessing
- Sales and product analysis
- Customer spending and loyalty analysis
- Customer churn-risk analysis
- Refund rate analysis
- Data visualization

## Key Findings
- Identified 88 customers at potential risk of churn.
- Home Goods had a refund rate of approximately 27.27%.
- Electronics had a refund rate of approximately 26.83%.
- Loyalty members had lower average transaction spending than non-members.

## Business Recommendations
1. Send targeted offers to at-risk customers to encourage repeat purchases.
2. Investigate high refund rates in Home Goods and Electronics.
3. Review loyalty rewards to encourage customer spending.
